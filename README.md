# DRAMA REMAKE · 短剧出海重制智能体

> 一个面向「短剧出海重制」场景的前端交互演示，覆盖从原始剧集解析、资产本地化改编、分镜转化到海外版视频生成的完整工作流。**纯静态 UI 原型，所有数据均为模拟数据，不连接任何后端服务。**

## 🌐 在线体验

**[👉 点击打开在线 Demo](https://chenyiwang325-droid.github.io/drama-remake-demo/)**

由 GitHub Pages 托管，打开即交互，无需安装。

本地打开 `index.html` 即可从项目列表进入工作台。视频工作室中的静态参考帧支持放大。

## 📐 产品定位

短剧出海重制智能体面向「把中文短剧批量重制为海外多语言版本」的场景，将原本依赖大量人工的解析、改编、生成工作，沉淀为四阶段流水线式的协作工具。本仓库为其**前端交互原型**，用于产品演示与设计沟通。

重制流水线四阶段：

```
① 剧集解析  →  ② 确定改编方向  →  ③ 资产与剧集改编  →  ④ 视频生成
```

## 🧩 功能模块

### 一、项目管理

打开演示后从项目列表选择要进入的项目。

| 功能 | 说明 |
|---|---|
| 项目列表 | 卡片网格，每张卡含项目名、总集数、创建时间、角色/场景数、目标市场、解析进度 |
| 创建 / 删除 | 新建项目（名称 + 短剧 ID）；删除需二次确认 |
| 项目工作台 | 进入项目后切换至工作台，含「短剧重制 / 团队管理 / 项目进度」三大类 TAB |
| 四阶段流程总览 | 默认展示完整四阶段流程，各阶段带状态与操作入口 |
| 导入与解析 | 上传视频 / 字幕，触发全集分析；单集状态色块网格（已完成 / 解析中 / 未开始）+ 整体进度条 |
| 解析结果 | 总集数 / 角色 / 场景 / 分镜统计，剧情梗概与分集故事概要 |

### 二、资产库

全剧角色、场景、道具的统一管理，是改编与生成的数据基础。

| 功能 | 说明 |
|---|---|
| 资产分类 | 角色 / 场景 / 道具 / 分镜 四个子 TAB；角色下挂多套服装，场景下挂多个状态 |
| 批量改编 | 一键对全部资产做本土化文本转化（名称 / 描述改写） |
| 批量生成 | 多选模式 → 勾选资产 → 参数选单 → 批量生图 |
| 资产详情 | 工作室式布局：固定信息区（原名 / 改编名、原版 / 改编描述）+ 素材生成区（参考图、提示词、生成结果、历史版本） |
| 提示词工具 | 提示词优化（AI 改写弹窗）、提示词反推（图 → 词）、添加参考图、生图参数选单 |
| 资产操作 | 新增、删除（含分镜引用自动迁移）、合并重复资产、编辑整体信息 |
| `@资产引用` | 在提示词中以 `@[资产名]` 引用其他资产作为参考 |

### 三、剧集改编

把每集分镜内容（对白、镜头描述）从中文转化为目标市场语言。

| 功能 | 说明 |
|---|---|
| 逐集卡片 | 一体化卡片列表，每集可展开查看分镜改编详情 |
| 分镜对照 | 每条片段含片段编号 / 时间、剧情简介、场景 / 人物 / 道具、提示词，均为「原始中文 ↔ 改编英文」左右对照 |
| 批量改编 | 顶部一键批量改编全剧分镜 |
| 特殊改编要求 | 每集可填写特殊要求（保存生效，入口圆点指示状态） |
| 检索 | 集号精确搜索 + 分集筛选 |
| 跳转创作 | 每集一键跳转视频生成页并定位到对应集 |

### 四、视频生成

基于改编资产与分镜，逐集生成海外版视频片段。页面采用「剧集选择看板 ↔ 单分镜生产工作室」两态切换。

| 区域 | 功能 |
|---|---|
| 剧集看板 | 默认态：剧集卡片网格，每集显示段数与「完成 / 进行中 / 未开始」状态 |
| 左栏 · 镜头索引 | 当前集镜头列表，支持集数切换、键盘翻页 |
| 中编辑区 | 三板块布局：分镜信息、提示词编辑、生成参数 |
| 右视频区 | 视频预览与成片播放 |
| AI 辅助 | 提示词优化、反推；参数配置（厂商 / 模型 / 画幅 / 分辨率 / 音画同步 / 时长 / 数量） |
| 模型厂商 | 平台模型 / 即梦 / 可灵 / Vidu（均为演示占位） |

### 五、团队协作与权限

| 功能 | 说明 |
|---|---|
| 团队管理 | 团队信息卡、成员缩略卡（三阶段任务概要）、成员详情与编辑 |
| 项目进度看板 | 整体概览、阶段进度、成员任务统计、各集进度（审核四态、按状态筛选） |
| 成员治理 | 角色切换、移交负责人、添加 / 移除成员 |
| 任务分配 | 资产库精细到具体资产、剧集改编按集、视频生成按集 —— 分配即权限 |

## ✨ 交互亮点

- **四阶段流水线总览**：未解析即可看到完整流程与每步说明
- **`@资产引用`光标菜单**：提示词中输入 `@` 唤起资产选择，跨资产复用参考
- **参数选单 Popover**：厂商 / 模型 / 画幅 / 分辨率 / 音画同步 / 时长 / 数量，位置自适应、不随选参关闭
- **多选批量操作**：资产库批量生成的多选模式（全选 / 已选计数 / 退出多选）
- **左右对照改编**：原始 ↔ 改编并排，直观比对
- **键盘翻页镜头**：工作室态下键盘切换镜头，弹窗钳制视口内
- **积分消耗模拟**：每个生成动作附带积分预估（积分图标 + 数字）
