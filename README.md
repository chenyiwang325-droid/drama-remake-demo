# DRAMA REMAKE · 短剧重制智能体（前端交互演示）

一个面向「短剧出海重制」场景的纯前端交互演示 Demo，模拟从剧集解析、资产转化到分镜视频生成的完整工作流。**本仓库为静态 UI 原型，所有数据均为模拟数据，不连接任何后端服务。**

## 功能模块

- **项目列表**：多项目管理，含目标市场、集数、进度
- **资产库**：角色 / 场景 / 道具资产的统一管理、引用检索与替换
- **剧集改编**：逐集分镜、对白改编、特殊要求标注
- **视频生成**：分镜到视频的参数配置（厂商 / 模型 / 画幅 / 分辨率 / 时长）、预览与成片管理

模型厂商选项含：平台模型、即梦、可灵、Vidu（均为演示用占位，不构成对任何服务的实际调用）。

## 本地运行

纯静态页面，无需安装依赖：

```bash
# 方式一：直接双击 index.html 打开
# 方式二：本地起一个静态服务
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 技术栈

原生 HTML / CSS / JavaScript（无构建工具、无框架），少量 SVG 图标内联。
